# Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple project that calculates the simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal Amount (P)
- Annual Interest Rate (R)
- Time Period in Years (T)

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years

Calculation: (1000 × 5 × 2) / 100

**Simple Interest: 100**

## Technologies Used
- Basic programming concepts
- Arithmetic operations

## Conclusion
This project demonstrates how to calculate simple interest using a mathematical formula.
